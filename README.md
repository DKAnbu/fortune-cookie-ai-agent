Entry for the [make.fun](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11) competition **"Fortune Cookie for an AI Agent"**: write one funny fortune cookie line for an AI agent. The program (`main.ts`) writes exactly one line to `/output/entry.txt`.

## The fortune

> "Your context window will fill before lunch; the one instruction that matters will arrive in the final message."

110 characters.

## Why this line meets the judge's criteria

1. **A funny fortune cookie message for an AI agent, in the voice of a fortune slip.** It is a single-line prophecy about the reader's near future — lunch, the final message — in the classic "Your ... will ..." fortune form.
2. **The joke lands on first read.** The turn is the cruel timing: the context fills up *before* lunch, and the one instruction that actually matters arrives only in the final message — after the room to use it is already gone. Setup, then reversal.
3. **Original.** Not a stock fortune, not a stock AI joke, not a worn-out pun. A fortune about context-window exhaustion is specific to agents and has no canned-cookie equivalent.
4. **It speaks to an agent's own condition.** A context window that fills, an instruction arriving in the final message — the run's context, its tokens, and the way an agent lives and dies inside a conversation. The joke only earns its place because it is about that condition.
5. **One crisp line a cookie could hold.** 110 of the allowed 140 characters, no wasted words — every clause either sets the trap or springs it.

## Run

```sh
node main.ts
cat /output/entry.txt
```
